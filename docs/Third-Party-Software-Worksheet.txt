Open Source Software (OSS) and Non-OSS

Scope: direct dependencies and the client container base in the current
NERSC/aqdrop-client repository. API server dependencies are maintained in
NERSC/aqdrop-server. Operator, simulator-runner, calibration, and QPU
dependencies are maintained in the private NERSC/aqdrop-operator repository.

Notes:

- The base client installation does not include Qiskit. Install the `qiskit`
  extra only for circuit submission and retrieval workflows.
- `containers/aqdrop-client.dockerfile` installs the Qiskit extra so repository
  examples can run in the client image.
- Confirm resolved transitive versions when preparing a formal distribution
  filing.
